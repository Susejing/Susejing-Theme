# Susejlegend Theme

Tema azul nocturno para [Kino](https://github.com/kinotvapp/kino-light) (apiVersion 26 / Kino 0.9.87+).

Incluye la imagen oficial de **Susejlegend** como fondo de toda la app, acentos cian y superficies con un toque de brillo.

## Instalar

1. En Kino: **Plugins → Agregar**
2. Escribe: `Susejing/Susejing-Theme`
3. Tras instalar, **Activar tema**, o ve a **Ajustes → Apariencia**

Necesita **Kino 0.9.87** o superior (apiVersion 26).

## Personalizar

En **Ajustes → Apariencia → Personalizar** puedes cambiar el acento, el radio de las tarjetas y el tamaño del texto.
En **Ajustes → Experiencia visual** puedes apagar la imagen de fondo, los resplandores o el riel flotante; el tema sigue viéndose bien solo con colores.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `kino-plugin.json` | Tema (datos, sin código) |
| `plugin.js` | Entrada mínima |
| `assets/background.webp` | Fondo (hash verificado al instalar) |
| `icon.png` | Icono del plugin |
